밴드 문서 이미지 넣는 곳
=========================

밴드(쿠팡AS·매출처업무)에 올라온 **거래명세서 / 세금계산서 사진**을 이 폴더에
그대로 복사해 넣으세요. 파일 이름은 아무래도 상관없습니다.

  지원 형식 : png · jpg · jpeg · bmp · tif · webp

넣은 뒤 앱 [실행] 탭에서 "밴드 문서 이미지 대조"를 누르면
  1) Windows 내장 OCR로 사진에서 글자를 읽고
  2) 발행일 · 명세서번호(또는 승인번호) · 프로젝트NO · 공급가액을 뽑아
  3) 관리대장과 맞춰본 결과를 reports/밴드문서OCR_*.csv 로 남깁니다.

"밴드 문서 → 대장 입력"을 누르면, 그중 **확실한 건만**(신뢰도 높음 + 금액 일치)
관리대장 빈칸에 자동으로 채웁니다. 이미 값이 있는 칸은 절대 덮어쓰지 않습니다.

■ 왜 인터넷 OCR을 안 쓰나
  거래명세서·세금계산서는 금융 문서입니다. 외부 서비스에 올리면 사진이 회사 밖으로
  나갑니다. 그래서 Windows에 내장된 한국어 OCR만 사용하며, 사진은 이 PC를 벗어나지
  않습니다.

■ 사진 찍을 때 요령 (인식률이 크게 달라집니다)
  · 문서를 화면에 꽉 차게, 위에서 똑바로 (기울어지면 숫자를 잘 틀립니다)
  · 그림자·빛 반사 피하기
  · 금액란이 잘리지 않게

■ 자동 검증
  공급가액 + 세액 = 합계, 세액 = 공급가액의 10% 를 만족하지 않으면 금액을 채택하지
  않습니다. OCR이 자릿수를 틀리면 이 검사에서 걸러지므로, 틀린 금액이 대장에
  들어가지 않습니다.
