고객사 로고(쿠팡 CI) 넣는 곳
================================

이 폴더에 로고 파일 하나를 넣으면 앱 상단·보고서·캡처 이미지의 로고가
자동으로 그 파일로 바뀝니다. 파일이 없으면 기본 CSOS 마크가 쓰입니다.

  파일명 : 아무거나 (예: coupang.png)
  형식   : png · svg · jpg · webp
  권장   : 배경이 투명한 PNG 또는 SVG, 가로 400px 이상

■ 공식 파일 받는 곳
  쿠팡 뉴스룸 → 미디어 자산·브랜드 가이드라인
    https://news.coupang.com/media-assets-brand-guidelines-kr/
    https://news.coupang.com/archives/1257/          (쿠팡 로고)

■ 브랜드 가이드라인상 지켜야 할 것 (쿠팡 고지사항)
  · 색상·서체·그림자·그라데이션·비율·방향을 **변형하지 말 것**
  · 이미지 위에 얹을 때는 **흰색 로고** 사용
  · 애니메이션 금지
  → 그래서 직접 그리거나 색을 바꾸지 않고, 받은 원본 파일을 그대로 씁니다.

■ 왜 저장소에 같이 커밋하지 않나
  이 저장소는 GitHub에 **공개**되어 있습니다. 타사 상표 파일을 공개 저장소에
  올리면 재배포가 되므로 .gitignore로 제외했습니다.
  (이 README만 커밋되고, 실제 이미지 파일은 이 PC에만 남습니다)
