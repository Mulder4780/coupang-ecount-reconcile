# 설정 화면 고도화 — 설계 (2026-08-15 지시)

사용자 지시: **"전체적으로 설정 기능을 고도화해서 앱의 설정 전체 컨트롤 할 수 있게
알고리즘 변경해, 설정이랑 관계 없는건 넣지 말고 정리해"**

> 이 문서는 **조사 결과와 설계**다. 구현은 아직 안 했다 — 컨텍스트가 차서
> 반쯤 고친 화면을 남기지 않으려고 여기서 끊었다. 다음 세션이 이것을 읽고 잇는다.

## ⚠ 0. 먼저 — 분담판 **[103]** 과 방향이 어긋난다 (2026-08-15 발견)

분담판에 이미 이런 항목이 있다:

> **[103]** 설정 관리자 통합 관제 허브 — 상태 스트립: `/api/system-audit`
> (state·healthy·summary·findings) 를 열 때 한 번 불러 **허브 각 타일/헤더에
> 현재 상태 표시**. 허브 그리드는 `dff263d` 로 완료

**[103] 은 그 16개 타일을 살려 상태를 붙이자는 것이고, 이 문서는 15개를 빼자는
것이다.** 둘 다 하면 뺀 자리에 상태를 붙이는 셈이라 한쪽이 헛일이 된다.

**먼저 형님께 어느 쪽인지 여쭌 뒤에 손댄다.** 짐작으로 한쪽을 고르면
옆 세션이 만든 `dff263d` 를 말없이 지우게 된다.

- 절충안(제안): 타일은 **업무 화면 바로가기가 아니라 '상태판'** 으로 뜻을 바꾼다 —
  누르면 그 화면으로 가는 것은 사이드바가 이미 하므로, 여기서는 **무엇이
  빨간지만** 보여 주고 그 하나만 누르게 한다. 그러면 [103] 의 상태 스트립은
  살고, '메뉴 복제'라는 성격은 없어진다.
- 어느 쪽이든 **설정 고유 기능(3절 A~D)은 그대로 필요하다** — 그건 [103] 과
  안 겹친다. 막히면 그것부터 한다.

## 1. 지금 무엇이 잘못돼 있나 (실측 2026-08-15)

### ① 설정 화면의 절반이 **설정이 아니다**

`#v-settings`(webapp/index.html:4513~4565)에 카드가 셋인데, 그중 제일 큰
**'관리자 기능 통합 관제'** 는 `routeNav()` 단추 **16개**다:

```
실행·자동화 · 시스템 진단 · 업무 워크플로우 · 일일 대조 · 확인 필요 ·
정산 · 매출 실적 · 돌발 AS · 정기점검 · 원격 제어 · 업무일지 ·
원본 자료 · 대표 보고 · 조직도 · 쿠팡 캘린더 · 화면 밝기 전환
```

**열여섯 중 열다섯이 업무 화면 바로가기다.** 사이드바에 이미 전부 있다 —
설정 화면이 메뉴를 한 벌 더 복제해 놓은 것이다. 진짜 설정은 마지막 하나
(`화면 밝기 전환`)뿐이다.

이것이 형님이 "관계없는 건 넣지 말라"고 하신 자리다. 그리고 이 복제는
**조용히 낡는다** — 새 화면을 만들어도 여기 단추는 안 늘고, 화면을 지워도
여기 단추는 남는다. 아무 오류도 안 난다.

### ② 진짜 설정은 **앱 곳곳에 흩어져 있다**

| 설정 | 지금 있는 자리 | 저장 열쇠 |
|---|---|---|
| 글꼴 프리셋 6종 | **[실행] 탭** 카드 (3898) | `csos_font_preset` |
| 화면 밝기(테마) | **상단 계정 줄** 단추 (3027) | `cw_theme` |
| 내 화면 구성(카드 순서·표시) | **[업무센터]** 탭 (3310) | `DASH_LAYOUT_KEY` |
| 조직도 자리 순서 | **[조직도]** 화면 길게 누르기 | `ORG_ORDER_KEY` |
| 설명·구역 접기 상태 | 화면마다 | `HELP_FOLD_KEY`·`SEC_FOLD_KEY` |
| 앱 설치(PWA) | 담당자 업무센터 안 | `csos_installed_*` |

**사람이 "설정을 바꾸려면 어디로 가야 하나"에 답할 수 없다.** 글꼴을 바꾸러
[실행]에 가야 한다는 것은 아무 화면도 알려 주지 않는다.

## 2. 무엇이 설정인가 — 가르는 근거 하나

**"이 값을 바꿔도 업무 자료는 한 글자도 안 바뀌는가?"**

- 예 → 설정이다 (글꼴·테마·카드 순서·접기·알림 채널·PIN·권한)
- 아니오 → 설정이 아니다 (원장·정산·AS·점검·보고 — 전부 업무 화면)

이 한 줄이면 흔들리지 않는다. **'관리자가 쓰는 것'을 설정이라 부르면 안 된다** —
그 기준으로는 앱 전체가 설정이 되고, 그래서 지금 16개가 들어와 있다.

## 3. 만들 것 — 설정 화면 한 장

### 구역 넷

**A. 이 기기 (서버에 안 간다 · localStorage)**
- 글꼴 — [실행] 탭에서 **옮겨 온다**(사본을 만들지 않는다)
- 화면 밝기 — 밝게 / 어둡게 / 시스템 동일
- 내 화면 구성 — 업무센터 카드 순서·표시 (지금 것을 링크가 아니라 **여기서 연다**)
- 설명 접기 초기값 · 조직도 자리 순서 초기화
- **이 기기 설정 초기화** 한 줄 (업무 자료는 안 건드린다고 명시)

**B. 계정·권한 (서버)**
- 현재 권한 · 적용 범위 · 기기 인증 만료 — 지금 것 그대로
- 권한 다시 확인 · 관리자 모드 종료 — 지금 것 그대로

**C. 보안**
- 관리자 PIN 변경 — 지금 것 그대로
- 담당자 PIN은 **여기서 안 바꾼다**(지금도 그렇다 — 그 문구 유지)

**D. 앱**
- 앱 설치 상태 (`installState()` 를 **빌린다** — 판정을 새로 만들지 않는다)
- 접속 주소(고정/터널/로컬) 표시
- 알림 채널 상태 — `config/notify.json` 이 없으면 **"앱 안 알림만 갑니다"**
  라고 정직하게 적는다(`[259]`)

### 뺄 것
- 관리자 기능 통합 관제 **16개 중 15개** — 전부 사이드바에 있다
- 남기는 것: 없음. `화면 밝기 전환`은 A 구역의 진짜 설정으로 흡수한다

## 4. 지켜야 할 것

- ★ **판정을 새로 만들지 않는다**(`[162]`). 글꼴은 `setFontPreset` / 테마는
  `toggleTheme` / 설치는 `installState` / 권한은 `/api/auth/session` — **이미 있는
  것을 부른다.** 설정 화면이 제 손으로 다시 판단하면 두 화면이 다른 답을 한다.
- ★ **옮기는 것이지 복제하는 것이 아니다.** 글꼴 카드를 설정으로 옮기면
  [실행] 탭에서는 **지운다**. 두 곳에 두면 한쪽만 고쳐지고, 그것이 지금
  16개 단추가 생긴 경위다.
- ★ **화면 표시로 권한을 만들지 않는다**(`[279]` 그대로). 관리자 여부는 서버
  서명 역할이 정하고, 담당자 주소에서는 설정 메뉴 자체가 안 보인다.
- ★ **못 읽으면 '정상'이라 하지 않는다**(`[169]`). 알림 설정 파일이 없으면
  "알림 꺼짐"이 아니라 **"채널이 하나도 없습니다 — 앱을 열어야 봅니다"** 다.
- ★ **아이콘은 톱니바퀴**(`[282]`) · 이미 그렇다.
- **업무값은 한 글자도 안 쓴다.** 설정 화면에서 SQLite 업무 표를 건드리는 길을
  만들지 않는다. PIN·역할만 서버로 가고 나머지는 전부 이 기기다.

## 5. 새 검증이 필요하다

`[284]` (다음 빈 번호 — 쓰기 전에 `python tests/synthetic_check.py` 로 확인할 것):

1. `#v-settings` 안에 `routeNav(` 가 **0회**여야 한다 (업무 화면 복제 금지)
2. 글꼴 카드(`data-fontkey`)가 **설정 화면 안에만** 있고 `#v-run` 에는 없다
   (사본 금지)
3. 설정 화면이 `setFontPreset`·`toggleTheme`·`installState` 를 **부르기만** 하고
   같은 판단을 다시 적지 않는다
4. `body.staff-mode` 에서 설정 메뉴가 숨겨진다 (지금 규칙 유지)
5. 설정 화면 안에 `/api/staff/entry`·`/api/ledger` 같은 **업무 쓰기 호출이 없다**

## 6. 남은 판단 (형님께 물을 것)

- **'내 화면 구성'을 설정으로 옮길까, 업무센터에 둘까.** 카드 순서는 그 화면을
  보면서 고치는 것이 자연스럽다 — 옮기면 오히려 불편할 수 있다.
  → 제안: **설정에는 '초기화'만** 두고, 편집은 지금 자리 그대로.
- 담당자(류지영·오종현)에게도 **이 기기 설정**(글꼴·밝기)을 열어 줄까.
  지금은 설정 메뉴가 담당자에게 안 보인다 — 그러면 담당자는 글꼴을 못 바꾼다.
  → 제안: 담당자에게는 **A 구역만** 보이는 축소판.
